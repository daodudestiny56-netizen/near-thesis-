The NEAR Agent Census

Every number on this page is computed from a random sample of NEAR blocks by code in this repository. Re-run it with python -m census reproduce. Nothing is typed in by hand.
Data: FastNEAR Transactions API, queried live and cached. Method, limits and the labelled set are documented in METHODOLOGY.md. "Automated" is a behavioural class: it includes AI agents, classic bots and infrastructure such as relayers; behaviour alone cannot separate them.
